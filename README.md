# Sistema de Rescate Animal – Actividad 3 (HTML5)

Proyecto académico de maquetación estructural para un sistema de control de rescate y adopción responsable de animales. Está desarrollado únicamente con HTML5 y etiquetas semánticas, sin hojas de estilo CSS ni JavaScript.

## Archivos del proyecto

- `index.html`: página principal y navegación del sistema.
- `reportar.html`: formulario estructurado para registrar un caso de un animal que necesita ayuda.
- `rescates.html`: tabla de consulta con ejemplos demostrativos de casos de rescate.

## Cómo ejecutar el prototipo

1. Descargue o extraiga todos los archivos en una misma carpeta.
2. Abra `index.html` en un navegador web.
3. Utilice los enlaces de navegación para acceder al formulario y al registro de rescates.

Los enlaces entre páginas son relativos; por eso, los tres archivos deben permanecer juntos en la misma carpeta.

## Elementos HTML5 aplicados

Se utilizaron elementos semánticos como `header`, `nav`, `main`, `section`, `article`, `aside` y `footer`. También se incorporaron metadatos, idioma español, etiquetas `label`, `fieldset` y `legend`, atributos de validación nativa en los campos del formulario, y una tabla con `caption`, `thead`, `tbody`, encabezados `th` y fechas mediante `time`.

## Validación

Los tres documentos fueron comprobados individualmente mediante el validador Nu HTML Checker de W3C. Las evidencias de validación se incorporan en el informe de la actividad.

## Alcance del prototipo

Esta entrega corresponde a una maqueta estructural HTML5. El formulario utiliza `action="#"` y no almacena ni transmite información, ya que el proyecto no incluye un servidor ni una base de datos. Los casos mostrados en la tabla son datos ficticios con fines demostrativos.
